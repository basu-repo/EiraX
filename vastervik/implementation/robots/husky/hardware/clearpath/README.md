# Copied Clearpath configuration

This directory is copied from the Halmstad Clearpath configuration. It describes
their A201/A200 Husky, attachments, controller limits and sensors.

Before physical deployment, compare `robot.yaml` with the actual robot serial
number, platform generation, sensor serial numbers, network addresses and mounts.
The custom 3D LiDAR override and Gazebo-related comments are not proof that the
physical LiDAR driver is configured.
