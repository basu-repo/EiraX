# System descriptions

This is design and status documentation, not executable configuration.

- `CURRENT_STATE.md`: implemented behavior, validation, limitations and pending physical work.
- `PIPELINE_DESCRIPTION.md`: end-to-end control/data flow.
- `guides/`: operator and developer procedures.
- `handoffs/`: notes for transferring work between teams.
- `math/`: coordinate, camera and control derivations.
- `omnet_fyi/`: networking/OMNeT++ background.

When behavior changes materially, update `CURRENT_STATE.md` and the relevant folder README. README files explain ownership and usage; the current-state document records what has actually been validated.
